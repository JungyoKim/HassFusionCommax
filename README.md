# HassFusionCommax

HassFusionCommax는 홈어시스턴트(Home Assistant)와 코맥스(Commax) 스마트홈 월패드 시스템을 완벽하게 연동하기 위해 개발된 하이브리드 브릿지 시스템입니다. 이 프로젝트는 **Go 기반의 백엔드 데몬**과 **Python 기반의 홈어시스턴트 커스텀 컴포넌트(Custom Component)**로 구성되어 있습니다.

## 🏗️ 시스템 아키텍처 및 작동 원리

월패드를 단순 연동하는 기존 방식들과 다르게, 본 시스템은 **RS485 시리얼 통신**과 **TCP 패킷 스니핑/HTTP 파싱** 기법을 동시에 결합하여 동작합니다. 빠르고 안정적인 통신을 위해 Go 언어로 작성된 데몬이 중간 브릿지 역할을 하며, 웹소켓(WebSocket)을 통해 홈어시스턴트와 실시간 상태를 동기화합니다.

### 1. Go 백엔드 데몬 (`hassfusion/`)
Go 데몬은 홈어시스턴트와의 통신을 유지하면서 하드웨어 및 서버 레벨 데이터를 수집/제어하는 핵심 엔진입니다.

- **RS485 네트워크 제어 (`rs485/`)**
  - 월패드 뒷면의 RS485 단자에 연결되어 조명, 난방(보일러), 일괄소등 장치, 현관 도어벨 등 물리적인 장치를 직접 조회하고 제어합니다.
  - 응답 지연을 방지하기 위해 각 장치별로 동시성 제어(Mutex 및 Channel)를 촘촘히 구현하여, 빠른 연속 제어 시에도 데드락이나 명령 무시가 발생하지 않도록 설계되었습니다.

- **SOAP/HTTP API 캡처 (`capture/`)**
  - **엘리베이터 상태**: 아파트 단지 관리 서버(CES)로 전송되는 SOAP XML을 주기적으로 폴링(Polling)합니다. 엘리베이터의 현재 층, 이동 방향, 호출 상태를 파악합니다. 서버 부하를 막기 위해 엘리베이터가 정지해 있을 때는 폴링 주기를 늦추는 알고리즘이 적용되어 있습니다.
  - **에너지 사용량**: 전기, 수도, 가스에 대한 연별, 월별, 일별, 시간별 사용량을 주기적으로 가져옵니다. 메모리 내에 이 값들을 캐싱해두어 홈어시스턴트 재시작 시 10분을 기다리지 않고 즉각적으로 값을 복원합니다.

- **TCP 패킷 스니핑 (`httpx/`)**
  - **공동현관 주차 알림**: 외부에서 월패드로 들어오는 이벤트 중에는 폴링으로 잡기 어려운 일회성 알림들(예: 주차장 입/출차 알림)이 있습니다. 이를 위해 라우터(방화벽) 단에서 들어오는 패킷을 실시간 스니핑(TCP Assembly)하여 차량 번호와 입출차 상태를 즉각 캐치합니다.

### 2. Home Assistant 커스텀 컴포넌트 (`custom_components/hassfusion/`)
홈어시스턴트에 설치되는 Python 플러그인입니다. 

- 사용자가 설정 화면(UI)을 통해 Go 백엔드 서버의 IP와 포트만 입력하면 손쉽게 연동됩니다 (`config_flow.py`).
- 내부적으로 `aiohttp` 웹소켓 클라이언트를 사용해 Go 데몬과 끊김 없이 데이터를 주고받습니다. 만약 연결이 끊어지면 지수 백오프(Exponential Backoff)를 이용해 부하 없이 재연결을 시도합니다.
- 조명(Light), 보일러(Climate), 스위치(Switch), 버튼(Button), 각종 센서(Sensor, Binary Sensor) 등 홈어시스턴트의 표준 엔티티 규격에 맞춰 데이터를 맵핑하므로 자동화(Automation) 작성에 매우 용이합니다.

## 🚀 설치 및 실행 방법

### 1. Go 데몬 실행
이 프로젝트의 `hassfusion` 폴더 내부 코드를 실행 환경(라즈베리파이, 미니PC 등)에 맞게 컴파일하여 실행합니다.

```bash
cd hassfusion
# 윈도우 환경 크로스 컴파일 예시 (리눅스용)
$env:GOOS="linux"; $env:GOARCH="amd64"; go build -o hassfusion_linux_amd64 main.go

# 실행
./hassfusion_linux_amd64 -config config.yaml
```
*사전에 `config.yaml` 파일에 RS485 포트 위치(ttyUSB 등)와 월패드 정보를 기입해야 합니다.*

### 2. Home Assistant 커스텀 컴포넌트 설치
위에서 실행한 Go 데몬과 통신할 홈어시스턴트 플러그인입니다.

1. 이 저장소의 `custom_components/hassfusion/` 폴더 전체를 여러분의 Home Assistant `config/custom_components/` 경로에 복사합니다.
2. 홈어시스턴트를 재시작합니다.
3. `설정` -> `기기 및 서비스` -> `통합 구성요소 추가` 버튼을 눌러 **HassFusion**을 검색하고 추가합니다.
4. 설치 대화상자에 Go 데몬을 실행해둔 장비의 IP 주소를 입력하면 자동으로 모든 기기를 불러옵니다.
